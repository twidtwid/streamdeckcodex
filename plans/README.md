## Release invariant

Every key must pass all applicable layers:

1. exact page, position, UUID, settings, label, and icon contract;
2. executable action-handler test with asserted dispatch arguments;
3. fail-closed test when focused-task identity or required UI is unavailable;
4. 144px and physical 72px render checks for clipping, overlap, edge collision,
   legibility, and nonblank glyph mass;
5. connected postcondition verification for stateful or Codex-mutating keys;
6. cleanup/restoration verification for any connected test that changes state
   or opens temporary tasks/windows.

## Findings considered and rejected

- Removing the Context key's 30-minute freshness rule was not planned. Current
  product documentation explicitly treats stale context as unknown; changing
  that is a product decision, not a confirmed implementation defect.
- The earlier decision not to upgrade dependencies was valid for the 2026-07-26
  snapshot. It is superseded by Plan 018 because the 2026-08-31 full audit found
  new development-chain advisories; the production-only audit remained clean.
- Additional icon redesign was not planned. The current generated atlas showed
  no confirmed border collision or placeholder-line defect; this plan set
  preserves and exhaustively validates the existing visual contract.
- Removing the tracked `.streamDeckProfile` archive was rejected. It is a
  reproducible distribution artifact used by Stream Deck installation.
- Removing model/reasoning pending-selection state was rejected. It represents
  an intentional dial preview that must remain distinct from applied live
  state.
- Deleting permission concurrency guards in isolation was rejected. Plan 008
  moves their single-flight/generation guarantees to one owner before removing
  action-local copies.
- The local progress feed and manual operator scripts were not classified as
  dead solely because package scripts have no internal caller; README and
  operator workflows still advertise plausible direct use.
- Broad Swift modularization, a provider abstraction, private renderer
  transports, and fork-derived feature additions are deferred. They are not
  required to restore current Model/Reasoning, Context/Permission diagnostics,
  input safety, or release correctness.
